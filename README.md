# RustMinus Bot

A Discord bot for Rust+ integration.

## Features
- 🎮 Smart device management
- 💬 Team chat monitoring
- 🔔 Event notifications
- 📷 Camera access
- 👥 Player tracking

## Setup
1. Clone: `git clone https://github.com/terminatorskynet600-web/rustminus.git`
2. Install: `pip install -r requirements.txt`
3. Configure your `.env` file
4. Run: `python bot.py`
